Privacy notice

How the AI Safety Standards & Publications Matrix and Products & Vendors Matrix handle information when you visit or use them.

Last updated: 3 September 2026

Information processed in your browser

The matrix data and application code are embedded in the site. Searching, filtering, sorting, changing pages, and creating a CSV export are performed locally in your browser. Those actions and the contents of exported files are not sent to the site operator or to Cloudflare Web Analytics.

Cloudflare Web Analytics

The two matrix pages use Cloudflare Web Analytics to understand aggregate traffic and page performance. The Cloudflare JavaScript beacon measures page views, referral sources, approximate country, device and browser characteristics, and web-performance metrics. It does not use cookies, collect search or filter values, or record URL query strings. Cloudflare states that Web Analytics does not collect or use visitors’ personal data.

Analytics are used only to understand which matrix pages are useful, how visitors find them, and whether the pages perform well. This site does not use analytics for advertising, cross-site profiling, or automated decisions about visitors.

For more information, see Cloudflare’s Web Analytics overview, analytics dimensions, and privacy policy.

Hosting

The public site may be delivered through GitHub Pages. GitHub states that it logs visitors’ IP addresses for security purposes when a GitHub Pages site is visited. See GitHub Pages data collection and the GitHub Privacy Statement.

External links

The matrices link to standards bodies, regulators, providers, GitHub, and other third-party sites. Their privacy practices apply after you follow those links.

Contact form

The contact form sends the name, email address, subject, message, and a short-lived human-verification token you provide to a Cloudflare Worker. Cloudflare Turnstile and the Worker process the request to detect automated abuse, enforce size and content limits, and validate the site hostname. Valid plain-text messages are passed through a privately configured Google Apps Script relay and delivered to the site administrator’s Gmail inbox. The destination address and private relay details are not disclosed to visitors.

The operator does not place contact submissions in a separate website database. Delivered messages remain in the administrator’s email account according to its retention settings. Cloudflare and Google may process request, security, diagnostic, and message data under their respective policies. The form does not accept files or create HTML email, but visitors should still avoid passwords, confidential information, and sensitive personal data.

See Cloudflare’s privacy policy, its Turnstile documentation, and Google’s privacy policy for more information.

Questions

Privacy questions can be sent through the contact form or raised through the project’s GitHub issue tracker. Do not include confidential or sensitive personal information in a public issue.
